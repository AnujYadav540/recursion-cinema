# Recursion Cinema 🎬

An interactive educational platform that helps students learn recursion through beautiful visualizations and step-by-step execution.

## ✨ Features

- **Interactive Code Editor**: Write and test recursive functions in real-time
- **Visual Stack Visualization**: See the call stack grow and shrink as your code executes
- **Recursion Tree Builder**: Understand the recursive call structure with an animated tree
- **Frame-by-Frame Playback**: Control execution speed and step through your code
- **Preset Examples**: Learn from built-in examples like factorial, Fibonacci, and more
- **Syntax Error Detection**: Get immediate feedback on code errors

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/AnujYadav540/recursion-cinema.git

# Navigate to project directory
cd recursion-cinema

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to see the application.

## 📦 Build for Production

```bash
npm run build
```

## 🧪 Running Tests

```bash
npm run test
```

## 🛠️ Tech Stack

- **React 18** - UI framework
- **TypeScript** - Type safety
- **Vite** - Build tool and dev server
- **Framer Motion** - Animations
- **Monaco Editor** - Code editing
- **React Flow** - Recursion tree visualization
- **Vitest** - Testing framework with property-based testing

## 📖 How to Use

1. **Choose a Preset**: Start with built-in examples or write your own recursive function
2. **Run the Code**: Click the Run button to execute your function
3. **Watch the Visualization**: Observe the call stack, recursion tree, and variable values
4. **Control Playback**: Use play/pause, step forward/backward, and speed controls
5. **Learn**: Read the explanations and understand how recursion works

## 🎯 Educational Goals

This tool helps students:
- Visualize how recursive calls build up and unwind
- Understand the call stack and execution flow
- Debug recursive functions more effectively
- Build intuition for recursion through interactive exploration
